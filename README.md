# FrontCamFix

Front camera broken? Every app gets the rear camera instead: FaceTime, video calls, selfie and ID checks keep working.

![FrontCamFix](https://muratkurt.github.io/assets/frontcamfix/banner.png)

## Install

Add `https://muratkurt.github.io/` in Sileo and install **FrontCamFix**. Needs PreferenceLoader and AltList.

## Requirements

- iOS 16 or 17 (iOS 18 and later not tested yet)
- RootHide or rootless

## Features

- **Every app** — Camera, FaceTime, video calls and Safari all get the rear camera. The front camera is never started.
- **Mirroring** — stock, off or on.
- **Excluded apps** — keep the real front camera.

12 languages. Everything else is in **Settings › FrontCamFix**.

Details and changelog: [package page](https://muratkurt.github.io/depictions/com.muratkurt.frontcamfix.html).
